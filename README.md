# Нейроаналитик контроля качества звонков

**Дипломный проект — AI-приложение для транскрибации и анализа записей разговоров менеджеров с клиентами.**

Разработан в рамках обучения в Университете Искусственного Интеллекта.

## 🎬 Видеодемонстрация

[▶ Смотреть демонстрацию приложения](AI_Call_Quality_Analyzer_Demo.mp4)

В видео показаны загрузка аудиозаписи и текстового диалога, транскрибация, AI-анализ, оценка этапов продаж, рекомендации и взаимодействие с AI-чатом.

## Возможности приложения

- Загрузка аудиозаписей и текстовых диалогов.
- Распознавание речи и преобразование аудио в текст с использованием OpenAI API.
- Анализ качества работы менеджера по пяти этапам продаж.
- Выявление ошибок и формирование рекомендаций.
- Интерактивный AI-чат для уточнения результатов анализа.
- Экспорт результатов анализа.

## Технологии

Python, OpenAI API, GPT-4o-mini-transcribe, Whisper, STT, React, TypeScript, Node.js, Express.

## Тестирование

Приложение протестировано на 12 демонстрационных записях разговоров по сценариям из 7 сфер бизнеса.

## Моя роль

Разработка и тестирование AI-приложения, работа с речевыми моделями, интеграция API, проверка результатов транскрибации и анализа диалогов.
